## Non-Goals

- No Qdrant, Kuzu, UMAP, GMM, adRAP, or other research-track work.
- No Postgres live migration.
- No server-side Nextcloud app in the MVP.
- No automatic deletes, moves, overwrites, canonical promotion, archive cleanup, or original-file mutation.
- No use of the human Nextcloud admin user.
- No live Provider, Telegram, Nextcloud, host, export/import, rebuild, or network action without explicit live Go.
- No real secrets, tokens, chat IDs, passwords, provider payloads, private file contents, or raw Telegram identifiers in docs, tests, logs, handoffs, fixtures, prompts, or automation text.

## Stop Rules

- Stop on foreign staged files, unclear dirty ownership, or hotfile conflicts.
- Stop if a slice would need files outside its allowed scope.
- Stop if implementation would begin before the `1.0.0` Go/Partial/No-Go handoff is documented.
- Stop if a real credential, token, password, chat ID, provider output, private source content, or raw external identifier would be persisted or quoted.
- Stop if a task requires live network, Provider, Telegram, Nextcloud, host, export/import, rebuild, backup, restore, or deployment action without explicit user Go.
- Stop before any delete, move, overwrite, restore into live paths, destructive git command, force push, or history rewrite.
- Stop if tests require real Nextcloud, Telegram, provider, or network access instead of fakes.

## Go / Partial / No-Go / Deferred

`Go` for starting 1.1 implementation:
- `1.0.0` Go or explicitly accepted Partial handoff is documented.
- Worktree has no foreign staged files or hotfile conflicts.
- Alice/Bob allowed paths are exact.
- No live action is required for the first implementation slices.

`Partial` for 1.1:
- Roadmap and offline models/tests are ready, but live Nextcloud, backup/restore, or deployment evidence is still pending.
- Backup artifacts may exist, but real `pre-update` snapshot plus restore smoke is not yet green.

`No-Go`:
- `1.0.0` handoff is absent or contradictory.
- Secrets or private provider/source output would leak.
- Source-provider work would require live credentials, network, host mutation, or real Nextcloud writes before gates are ready.
- No-delete/copy-only/review-gated policy is not enforceable or not documented.

`Deferred`:
- Telegram Voice download/STT/reply.
- Server-side Nextcloud app.
- Live Nextcloud writes.
- Host backup/restore execution.
- Research/accelerator tracks.
