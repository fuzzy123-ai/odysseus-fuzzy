Coding Lane Notes

Text and markdown files open as quiet writing surfaces. The formatting controls stay small, direct, and limited to what a normal person expects while writing.

Editor Rules

  • Large writing area first.
  • Formatting is available, but not dominant.
  • Markdown and plain text should feel like one simple editor.

The viewer should not look like an IDE unless the content is actually code.

Release Notes

This page represents PDF and office-style documents. The viewer keeps page state and zoom tools visible, but they stay small and out of the reading path.

A document can be read, zoomed, paged, and later connected to the rest of Odysseus without turning this surface into a dashboard.

Images do not need to live here. They can open in the dedicated image editor window.
