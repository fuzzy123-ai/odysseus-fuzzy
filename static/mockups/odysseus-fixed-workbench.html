Frontend V2 – Shell Contract

Die globale Navigation besteht aus vier stabilen Orten. Alle weiteren Werkzeuge öffnen als Tabs in einer festen Editorfläche oder als kontextuelles Unterpanel.

Layout invariants

  • Keine globale Sidebar und keine schwebenden Fenster.
  • Alle Split-Grenzen sind größenverstellbar und zurücksetzbar.
  • Aktive Orte, Tabs und Panelzustände sind eindeutig sichtbar.
  • Command-Palette bleibt der schnelle Weg zu seltenen Werkzeugen.

Notes

Notizen verwenden denselben festen Editorbereich. Listen, Editor und Metadaten können über die vorhandenen Splitter verteilt werden.

Memory

Memory wird als durchsuchbare Wissensansicht behandelt, nicht als modales Spezialfenster. Auswahl und Details bleiben dauerhaft nachvollziehbar.

Skills Library

Skills, Audit-Zustände und Entwürfe teilen sich diese Editorfläche. Der rechte Bereich zeigt den gewählten Skill-Vertrag.

Gallery

Galerie und Bildeditor öffnen als feste Editor-Tabs. Der Editor kann die gesamte mittlere Fläche übernehmen, ohne andere Fenster zu überlagern.
